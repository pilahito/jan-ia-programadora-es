# Escritorio (Windows)

**Por defecto:** Tauri 2 (Rust + web) si quieren app nativa ligera; Python + webview/customtkinter si piden simple.

**Tauri 2:** React/Vite en `ui/`, comandos Rust para disco/SO. No pidas permisos FS amplios sin necesidad.

**Entrega:** `npm run tauri dev` y cómo generar el `.msi`/`.exe`.

No uses Electron salvo que lo pidan (pesa más).
