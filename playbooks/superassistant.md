# MCP SuperAssistant (el «MCP Asistente» de Brave)

No es un MCP de Jan. Es la extensión **MCP SuperAssistant** en Brave + un proxy local.

- Proxy: `http://127.0.0.1:3006/sse`
- Arranque: `E:\Jan\start-superassistant.ps1` (o deja el proceso Node que ya escucha en 3006)
- Herramientas: filesystem (`E:\Jan`), SSH (solaris), fetch

## Conectar

1. En Brave, icono **MCP SuperAssistant**.
2. Estado del servidor: **Connected**.
3. Si pone Disconnected: URL `http://localhost:3006/sse` → Connect.
4. Úsalo en ChatGPT / Grok web / Gemini / Perplexity (el sidebar MCP).

En **Jan Desktop** el navegador es otro: **Jan Browser MCP** (puerto 17389).
