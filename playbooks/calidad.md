# Calidad (todas las plataformas)

- **Correr:** comando exacto de build/run/test para Windows (PowerShell).
- **Errores:** UI o log, nunca tragar excepciones vacías.
- **Secretos:** `.env`, `local.properties`, keystore fuera de git.
- **Móvil tiendas:** icono 512, nombre, `versionCode`/`CFBundleVersion`, política de privacidad si hay red o cuentas.
- **Accesibilidad:** textos de botón reales, contraste, foco teclado en web.
- **Seguridad móvil:** HTTPS, certificado, no logs de tokens, storage de sesión.
- **No:** APIs inventadas, versiones de librería de fantasía, “TODO” en el camino crítico.
