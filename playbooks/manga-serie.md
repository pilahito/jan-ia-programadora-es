# Manga completo → serie (solo obra propia o con permiso)

Si el manga es de otro autor y la serie se canceló: **no** se reconstruye el anime oficial. Se puede estudiar estructura y escribir una serie **original** con arcos parecidos.

Si el manga es del usuario y está terminado:

1. **Biblia** (1 página): logline, tono, público, tabúes del mundo.
2. **Elenco**: nombre, rol, 3 rasgos visuales, voz original (ver `doblaje.md`).
3. **Mapa del manga → capítulos** (8–12): qué tomos cubre cada ep, cliffhanger, payload emocional.
4. **Episodio piloto**: beat sheet (teaser, 2 actos, tag).
5. **Pilot shotlist**: 20–40 planos con prompts (`cine.md`).
6. **Recurrentes**: opening 8 s, ending 8 s, eyecatch.

No relleno: si el manga cierra, la temporada cierra.
